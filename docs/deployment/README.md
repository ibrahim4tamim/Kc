# توثيق النشر — Deployment Documentation

> ⏳ عنصر نائب — يُملأ لاحقًا بتوثيق النشر والتشغيل.

النشر الحالي (نسخة v1.0): **Vercel** (إعدادات Next.js الافتراضية) مع
تخزين الصور عبر **Vercel Blob**، وربط **Netlify** متاح (`netlify.toml`).

متغيرات البيئة المطلوبة:
`NOTION_API_KEY`، معرفات القواعد الأربع، `WHATSAPP_NUMBER`،
`NEXT_PUBLIC_WHATSAPP_NUMBER`، `BLOB_READ_WRITE_TOKEN`.

راجع خطوات النشر في [`README.md`](../../README.md) بالجذر.
