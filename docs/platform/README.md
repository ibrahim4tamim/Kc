## بنية التوثيق الكاملة

```
docs/
├── legacy/       توثيق النسخة الأولى v1.0 المحفوظ كما هو
├── platform/     توثيق المنصة (هذا المجلد)
├── api/          توثيق واجهات API
├── database/     توثيق نموذج البيانات (Notion كـ SSOT حاليًا)
├── deployment/   توثيق النشر والتشغيل
└── decisions/    سجلّ قرارات المعمارية (ADRs)
```

> ⏳ = يحتاج المحتوى المعتمد النهائي. العناوين مبدئية حتى تتوفر الوثيقة الرسمية.
