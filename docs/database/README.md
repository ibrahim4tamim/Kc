# توثيق نموذج البيانات — Database Documentation

> ⏳ عنصر نائب — يُملأ لاحقًا بتوثيق نموذج البيانات.

في نسخة v1.0، **Notion** هو المخزن والمصدر الوحيد للحقيقة (SSOT) — لا قاعدة
بيانات خارجية ولا ORM. القواعد الأربع:

| القاعدة | الدور |
|---|---|
| Sourcing Requests | المركز: بيانات العميل والمنتج والحالة (24 حالة) |
| Suppliers | المورّد يُسجَّل مرة ويُربط بطلبات متعددة |
| Quotations | كل عرض = طلب واحد + مورد واحد بتاريخه الكامل |
| Communications | كل تفاعل مهم مع العميل (يدوي + تلقائي) |
