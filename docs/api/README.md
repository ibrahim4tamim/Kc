# توثيق واجهات API — API Documentation

> ⏳ عنصر نائب — يُملأ لاحقًا بتوثيق مسارات API.

المسارات الحالية (نسخة v1.0):

| المسار | الغرض |
|---|---|
| `POST /api/requests` | إنشاء طلب توريد + رقم فريد + تسجيل تواصل |
| `POST /api/track` | تتبّع الطلب (تحقق هوية → DTO مسموح فقط) |
| `POST /api/quotes/feedback` | رد العميل على العروض المعتمدة |
| `POST /api/upload` | رفع صور المنتج → Vercel Blob |

راجع [../platform/ARCHITECTURE.md](../platform/ARCHITECTURE.md) للتفاصيل.
