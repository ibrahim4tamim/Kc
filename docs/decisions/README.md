# سجلّ قرارات المعمارية — Architecture Decision Records (ADRs)

> ⏳ عنصر نائب — تُضاف قرارات المعمارية هنا كملفات مرقّمة.

## الصيغة

كل قرار في ملف مستقل: `NNNN-عنوان-القرار.md` (مثال: `0001-notion-as-ssot.md`).

نموذج مقترح لكل ADR:

```
# NNNN — عنوان القرار
- الحالة: مقترح / معتمد / مرفوض / متجاوَز
- التاريخ: YYYY-MM-DD

## السياق
## القرار
## البدائل المدروسة
## النتائج والتبعات
```

## قرارات موثّقة ضمنيًا في v1.0 (تحتاج تحويلها إلى ADRs)

- اعتماد **Notion كمصدر وحيد للحقيقة** بدل قاعدة بيانات + ORM.
- **بدون نظام مصادقة** — تحقق العميل عبر رقم الطلب + جوال/بريد.
- **رقم طلب عشوائي** بدل تسلسلي (تجنّبًا لتعقيد العدّاد الذرّي).
- **بدون قاعدة Activity Log خامسة** — الاعتماد على Communications + تعليقات Notion.
